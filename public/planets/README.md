# Planet image assets

These images are downloaded from the NASA Image and Video Library asset host and used locally by the app so the UI does not depend on remote image URLs.

NASA image identifiers:

- Mercury: PIA15162
- Venus: PIA00271
- Earth: PIA18033
- Mars: PIA00407
- Jupiter: PIA04866
- Saturn: PIA01364
- Uranus: PIA18182
- Neptune: PIA01492
- Moon: PIA00405

NASA media are generally available for educational and informational use under NASA's media usage guidance. Verify current NASA usage guidance and any image-specific credit requirements before commercial publication.
